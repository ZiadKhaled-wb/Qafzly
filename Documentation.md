## 1. Executive Summary

### 1.1 The Opportunity

Egypt's digital education and e-learning market is valued at **USD 875 million**, driven by government initiatives, rising internet penetration, and demand for flexible learning solutions. The broader Egypt E-Learning and Digital Upskilling Market is valued at **USD 1.2 billion**. With a young population of over 60% under 30 and 70% smartphone penetration, there is a massive, underserved demand for Arabic tech education.

Yet the market gap is clear:
- **90% of tech education is in English** – creating a language barrier for millions
- **Traditional courses have <10% completion rates** – learners lose motivation
- **Quality Arabic content for youth is virtually non-existent**
- **Parents have no visibility** into what their children are learning online

### 1.2 The Solution: Qafzly

Qafzly is a **gamified, mobile-first educational platform** designed specifically for **Egyptian youth aged 12–17**, teaching technology fundamentals through structured **"Paths"** in Arabic and Egyptian dialect.

Unlike traditional EdTech platforms, Qafzly is built around three core differentiators:

| **Differentiator** | **What It Means** |
| :--- | :--- |
| **🎮 Gamified Learning** | XP points, levels, badges, streaks, leaderboards, and a free technical game |
| **👨‍👩‍👧‍👦 Parent-Centric** | Parent dashboard with progress tracking and voice support for illiterate parents |
| **🇪🇬 Egyptian-First** | Full Arabic content in Egyptian dialect – the language of our users |
| **📚 Curated Content** | Predefined, in-house developed "Paths" – not a marketplace |
| **🤝 Social Impact** | Scholarship program for underprivileged youth |

### 1.3 The Business Model

| **Revenue Stream** | **Description** |
| :--- | :--- |
| **Per-Path Subscription** | Pay once for access to a complete Path |
| **Monthly Subscription** | Unlimited access to all Paths |
| **Quarterly Subscription** | Unlimited access + 1 month free |
| **Annual Subscription** | Unlimited access + 3 months free |
| **Family Plan** | Up to 3 children under one subscription |

### 1.4 Social Impact

- **100,000+ youth** learning tech skills within Year 1
- **Scholarships** for underprivileged students
- **Digital literacy** for the next generation
- **Economic mobility** through tech skills

## 4. The Product: "Paths"

### 4.1 What is a "Path"?

A **Path** is a structured, introductory learning journey designed specifically for young learners. It is **not** a full course – it is a **gateway** to understanding technology.

| **Characteristic** | **Description** |
| :--- | :--- |
| **Duration** | 3–7 modules, 30–60 days |
| **Goal** | Introduction and exploration, not mastery |
| **Prerequisites** | None – designed for absolute beginners |
| **Age Appropriateness** | 12–17 years, tailored content |
| **Learning Style** | Visual, interactive, hands-on, playful |

### 4.2 Proposed Paths (Launch)

| **Path Name** | **Description** | **Modules** | **Target Age** |
| :--- | :--- | :--- | :--- |
| **Intro to Computers** | What is a computer? Hardware, software, basic operations | 5 Modules | 12–14 |
| **Intro to Internet** | How does the internet work? Websites, browsers, online safety | 5 Modules | 12–14 |
| **Intro to IT** | Information Technology basics, networks, data, security | 6 Modules | 14–16 |
| **Intro to Programming (Python)** | Programming basics, logic, problem-solving | 7 Modules | 15–17 |

### 4.3 Path Structure

```
PATH: Intro to Computers (5 Modules)
│
├── Module 1: What is a Computer? (3 Lessons)
│   ├── Lesson 1: The History of Computers
│   │   ├── Overview Video (3-5 min)
│   │   ├── View-Only PDF Explanation
│   │   ├── Explanatory Video (5-7 min)
│   │   ├── Interactive Slides (Concept → Question → Continue)
│   │   ├── Challenge: "Find the Computer" – Identify computer parts
│   │   └── ⏳ 12-Hour Lock before next lesson
│   ├── Lesson 2: Hardware – The Physical Parts
│   │   └── ... (similar structure)
│   └── Module Quiz: Comprehensive assessment after Module 1
│
├── Module 2: Software – The Digital World (4 Lessons)
├── Module 3: Using the Computer (4 Lessons)
├── Module 4: Keyboard Ninja
│   ├── Lesson: Being a Keyboard Ninja
│   │   ├── Challenge: Download zip file, uncompress it,
│   │   │              find a specific line using only the keyboard,
│   │   │              copy and paste it
│   └── Module Quiz
└── Module 5: The Future of Computing (2 Lessons)
    └── Final Path Quiz
```

### 4.4 Lesson Structure

| **Component** | **Description** | **Purpose** |
| :--- | :--- | :--- |
| **1. Overview Video** | 3-5 minute introduction | Engage, set expectations |
| **2. View-Only PDF** | Detailed explanation (no download) | Reference material |
| **3. Explanatory Video** | 5-7 minute concept explanation | Visual learning |
| **4. Interactive Slides** | Concept → Question → Continue | Active learning, comprehension checks |
| **5. Challenge** | Practical hands-on task | Skill building |
| **6. Module Quiz** | Comprehensive assessment | Summative assessment |
| **7. 12-Hour Lock** | Must wait before next lesson | Prevents rushing, ensures retention |

### 4.5 Content Ownership & Creation

| **Aspect** | **Decision** |
| :--- | :--- |
| **Content Creator** | Qafzly in-house team only |
| **Instructors** | None – no external instructors |
| **Content Updates** | Qafzly team reviews and updates periodically |
| **Content Type** | Predefined, curated "Paths" |
| **Quality Control** | Every piece reviewed and approved |

### 4.6 Beyond Lessons – Enhanced Content Structure (Sprint 10)

To increase engagement and reinforce learning, each lesson and module now supports additional interactive components:

| **Component** | **Description** | **Purpose** |
| :--- | :--- | :--- |
| **Warm-Up** | Riddle or short prompt at the start of a lesson | Spark curiosity |
| **Slides** | 5 interactive slide types: Info, Quiz, Drag & Drop, True/False, Fill-in-the-Blank | Micro-learning, active recall |
| **Mini-Quest Checkpoints** | In-lesson missions with hints and XP rewards | Gamified practical application |
| **Boss Battle** | End-of-module challenge with scoring, victory levels, and XP bonus | Summative, high-engagement assessment |
| **Recharge (XP Boost)** | 2x XP window after completing a lesson, valid for a limited time | Encourage spaced repetition |

## 7. Technology Architecture

### 7.1 Core Technology Stack

| **Layer** | **Technology** | **Rationale** |
| :--- | :--- | :--- |
| **Frontend** | React.js + Vite + TypeScript | Modern, fast, mobile-first |
| **Styling** | Tailwind CSS + shadcn/ui | RTL support, accessibility |
| **Backend** | Node.js + Express v5 + TypeScript | Scalable, large ecosystem |
| **ORM** | Prisma (pinned to 6.19.0) | Type-safe database access |
| **Database** | PostgreSQL | Reliable, ACID compliant |
| **Cache** | Redis | Session management, rate limiting |
| **Storage** | AWS S3 (me-south-1) | Egyptian regulatory compliance |
| **Video Hosting** | YouTube (unlisted) | Cost-effective, domain-restricted |
| **Payment** | PayMob (manual MVP first) | Local Egyptian gateway |
| **Code Execution** | Pyodide (client-side) | No server costs, instant feedback |
| **Testing** | Jest (unit) + Supertest (integration) | High-confidence releases |

### 7.2 Content Delivery

| **Content Type** | **Delivery Method** | **Security** |
| :--- | :--- | :--- |
| **Videos** | YouTube (unlisted) | Domain restriction, no ads, no comments |
| **PDFs** | View-only via PDF.js | Signed URLs (5 min TTL), watermarking |
| **Images** | AWS S3 | Signed URLs (1 hour TTL) |
| **Interactive Slides** | In-browser HTML | Platform-hosted |

### 7.3 Security & Compliance

| **Aspect** | **Implementation** |
| :--- | :--- |
| **Data Residency** | AWS Middle East (me-south-1) – Egypt-compliant |
| **Encryption** | At-rest (SSE-S3) and in-transit (HTTPS) |
| **Access Control** | Strict IAM policies, signed URLs |
| **User Privacy** | GDPR-compliant, COPPA-compliant |
| **Parental Consent** | Required for users under 18 |
| **Auth** | JWT access + refresh tokens, refresh stored in Redis |
| **Account Security** | Bcrypt password hashing (12 rounds), account lockout after failed attempts |
